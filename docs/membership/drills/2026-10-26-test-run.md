## Machine-readable summary

The runner writes the summary to the path given as its argument. Example run:

```bash
scripts/membership-test-all.sh [--branches] /tmp/m2-summary.json
```

Fields per suite:
- `suite`, `ref`, `commit` (with `+dirty` when tracked files are modified);
- `pass`, `fail`, `skipped`, `todo`, `tests`;
- `durationMs`, `exitCode`, `log`.

It also writes an overall `ok` and `total`. The exit code is 0 when every suite passed, 1 when a suite failed, and 2 on a setup error.
